# Celular e iPad

Instala el complemento en la bóveda y sincroniza tanto las notas como `.obsidian/plugins/neuronas`. Puedes hacerlo desde una computadora con el ZIP Plugin o el instalador Windows. En el dispositivo, habilita los complementos de comunidad y activa Neuronas.

Usa el método de sincronización que admita tu dispositivo. iCloud sirve para la bóveda compartida entre Windows y dispositivos Apple; Android necesita otro método compatible. Neuronas no configura el servicio de sincronización.

## Escribir

Toca **Escribir una nota**. El recuadro de captura es amplio y los campos usan letra de 16 px para facilitar la escritura. La ventana se adapta al espacio disponible al abrir el teclado y mantiene a mano Guardar. Puedes revisar título, materia, proyecto y etiquetas o guardar las sugerencias. El borrador dura mientras Obsidian siga abierto.

El tablero tiene selectores de estado para usarlo sin arrastrar tarjetas. La red permite tocar nodos, moverlos, acercar y abrir la nota de origen.

## Conversar con IA

En Ajustes → Neuronas elige proveedor, modelo y credenciales. Las APIs pueden tener coste separado de una suscripción de chat. Ollama necesita un servidor accesible: `localhost` en el teléfono es el propio teléfono.

El chat de nube funciona sin la PC encendida. Para recibir conversaciones nuevas de consolas, la PC debe capturarlas y la bóveda debe sincronizarse. Los recuerdos ya descargados se pueden consultar localmente.

## Comprobaciones

Se comprueba el arranque del complemento sin módulos de Node y se prueban pantallas estrechas y reducción de espacio del teclado en navegador. Falta la prueba física de sincronización y teclado en iOS/Android. Si un archivo aún no se descargó, el panel permite continuar con los disponibles y reintentar la lectura.

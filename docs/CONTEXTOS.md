# Contextos

El sistema puede trabajar con varios contextos educativos y laborales sin fijarlos en el código.

## Educación

Dentro de `02 - Universidad` puede haber múltiples instituciones, programas, periodos y materias.

## Trabajo

Dentro de `03 - Trabajo` puede haber múltiples empresas, clientes o contextos laborales.

## Contexto activo

La instalación puede guardar un contexto educativo y uno laboral como activos para priorizar acciones, búsquedas y sugerencias.

Cambiar el contexto activo no borra ni mueve información histórica.
